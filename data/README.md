# Input data

The notebooks use CT/NIfTI images for Person1 and Person2 and individual tooth masks
from the segmentation workflow. Raw scans, tooth masks and acquisition / consent
documentation are not included. No sample image download is promised.

Selected HU profiles and derived ratios are included under `results/`. They allow
readers to inspect the prototype outputs without running image processing.
The notebooks preserve original Colab / Google Drive paths for historical context.
Executing them requires authorized images and masks plus appropriate dependencies.
